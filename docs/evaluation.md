## 1. 研究问题

两个问题分开检验：

1. **假设**：在参赛实现之外，再增加一名仓库内评审，能否减少错误的确定判断。证据门槛的参赛定义见 [术语表](glossary.md#5-证据门槛)。这组对照不是参赛实现。
2. **假设**：结构化诊断包及轨迹能帮助仓库外的评审 agent 更准确、更快地定位缺陷。诊断包字段见 [术语表](glossary.md#6-诊断包)。

## 2. 数据

[SciFact](https://github.com/allenai/scifact/blob/master/doc/data.md) 的标签与证据来自摘要。它适合摘要级流水线自检，不能当作 PMC 全文评测结果。SciFact 结果单独报告，不与全文实验混算。

另从引文所在论文和被引文献都逐篇核实许可的 PMC 全文中，收集“论断与被引文献”配对。先导集用于改进标注指南，不并入冻结的正式测试集。

**研究目标**：正式集不少于 120 对。这是样本规模目标，不是产品验收条件，也不是已经收集到的数量。

可用 Agent 预标注以减少整理工作。用于报告准确率的真值，须由两名独立人员核对来源身份、判断标签与原文位置，分歧仲裁并报告一致性。这是研究基准的制作方式，不是产品逐条运行时的人工核验。

按论文分组切分，避免同一论文同时进入调试集和测试集。受控故障样本单列，不改变自然样本的类别比例。

## 3. 核验对照

在同一 PMC 测试集上比较四组：

1. 只给被引文献摘要的直接判定。
2. 使用相同的候选全文片段，但取消证据门槛。
3. 有证据门槛的单 Agent。
4. 在参赛实现之外，另加一名仓库内评审的对照系统。这组不是参赛实现。

第 4 组用来检验额外评审角色是否有净收益，不进入参赛实现。主要对照使用 `evaluation` 配置，固定模型部署、提示词、样本、来源快照、检索配置和调用预算，禁用跨模型/部署回退及模型响应缓存。参赛单 Agent 的查询生成、补读和输出修复不计为第二名评审。DeepSeek 等模型作为另行报告的跨模型实验，不通过自动回退混入主要结果。模型切换规则见 [D6](tech-stack.md#d6-模型适配)。

每次运行记录模型别名、配置模型、上游返回模型与可验证版本、参数、提示词版本、数据集与来源快照哈希，以及每个逻辑请求和上游尝试的 token、延迟与恢复原因。无法验证的真实版本、缺失的 usage 均显式记为未知，不以别名或零替代。

采样在运行前冻结：首版小规模验收每样本每条件 n=1，仅报告单次抽样，不报告重复采样稳定性或由重复运行估计的不确定区间。正式研究每样本每条件 n=3，三次均进入结果而非挑最好的一次；报告每轮指标、汇总及同样本三次学术标签完全一致的样本比例。稳定性分母只限三次均 COMPLETED 的样本，同时报告该子集占全部样本的比例和执行状态一致率，不能通过剔除失败声称整体稳定。置信区间按论文分组重采样，保留组内样本/重复相关性；样本不足时报告无法可靠估计，不把三次抽样当作独立论文。

## 4. 质量指标

### 分母与对账

运行前冻结样本、条件与重复编号，每个槽位对应一次任务结果；重试和重提单列新运行，不用新成功覆盖旧失败。对固定批次记录互斥恒等式：`N = D + I + B + F + C + X + U`。D 为 COMPLETED 且标签为支持/部分支持/相矛盾，I 为 COMPLETED/证据不足，B 为 BLOCKED，F 为 FAILED，C 为 CANCELLED，X 为 INTERRUPTED，U 为 QUEUED/RUNNING 及尚未创建任务的计划槽位。证据不足是完成的学术结果，但不是确定判断。取消及中断已终止，不能算仍在执行。

U>0 时报告进度和上述计数，任何中间指标明确标为暂定，不发布最终质量结论。批次封存前须结算 U，不能删掉未完成样本。最终可判定覆盖率 = D/N；B/F/C/X 均保留在分母，真值为证据不足也保留。另报真值可判定子集的覆盖率 D_g/N_g，不与全批次混称；D_g 是该真值子集内输出确定判断的数量，N_g 是该子集全部槽位数；这里真值可判定明确指支持、部分支持、相矛盾三类。所有比率分母为零均记 N/A 并给出计数。人工取消的边界测试另属控制测试批次，不能临时把质量批次中的取消样本移除以美化数字。

应拒判真值集合 R 仅指独立标注为证据不足的样本，不能按系统输出倒推。主要错误确定判断率 = R 中输出 D 的数 / R 中 COMPLETED 的数，并同时报告 R 总数、COMPLETED 数与比例及 B/F/C/X 数；无 COMPLETED 则 N/A。另报 R 中输出 D 的数 / R 总数作为全批次发生率，但不能将执行失败当作正确拒判或只用后一数字证明安全。召回率/F1 的真值分母保留所有封存质量槽位，B/F/C/X 没有学术预测，计入其真实类别的 FN。

F 按 BUDGET_EXCEEDED、各 UPSTREAM 错误、TASK_TIMEOUT、模型/摘录错误、RETRIEVAL_FAILED、其他未知分别计数，再给总数；B 按术语表的来源与处理/内容阻断分列并保留具体码。未知原因不猜测归类。同时报告调用账 verified/unverified 的数量、已知用量和未知项；元数据不全的样本不从学术指标分母删除。

分别报告：

- 可判定覆盖率
- 应拒判样本上的错误确定判断率
- 来源匹配准确率
- 证据 Recall@k
- 摘录定位有效率
- 判断 macro-F1，只在独立基准标为可判定的样本上计算
- 四类学术标签的 precision/recall；单列“相矛盾”的精确率、召回率（证据冲突识别率）、TP/FP/FN、真实样本数及预测数

precision=TP/(TP+FP)，recall=TP/(TP+FN)，分母为零报告 N/A。真值为相矛盾但系统拒判或执行失败的样本计入该类 FN，不通过只统计成功任务抬高召回率。macro-F1 等权汇总各类，不因小类样本少而自动降低其权重，但汇总数不能替代逐类结果。macro-F1 仍针对真值可判定子集的支持、部分支持、相矛盾三类，按 F1=2TP/(2TP+FP+FN) 计算；分母为零的类列出 N/A 并从平均中排除，报告实际参与平均的类别，全无定义则整体 N/A。四类逐类 precision/recall 在完整学术标注集上另报，不丢掉证据不足真值样本。

报告实际样本数、类别分布及按采样协议可估计的不确定区间。覆盖率低的系统，不用条件准确率表示成整体更优。

## 5. 故障归因实验

单独注入身份错配、许可缺失、检索遗漏、上游超时/限流、认证失败、检索数据库异常、任务总超时、预算耗尽和摘录错配。实现阶段须将注入生成脚本、夹具定义与确定性断言纳入版本控制；固定随机种子及版本，实际注入参数和结果保存到访问受控的验证归档，凭许可决定是否入库，敏感正文不提交。注入清单只供评测器使用，不放进 [输入诊断包](glossary.md#6-诊断包)。

让仓库外的固定评审 agent 比较三种输入，并按样本平衡顺序：

1. 只看最终输出。
2. 看结构化诊断包，但不看轨迹。
3. 看诊断包和轨迹。

测量根因分类准确率、证据引用正确率、错误修复建议的可复现率、耗时和 token 成本。真因由注入记录和确定性断言给出，不要求人员逐例排障。轨迹无法判定的根因，允许评审回答不确定。外部评审返回值里的 `insufficient_evidence` 是故障归因结论，不是结果标签「证据不足」。

自然论文样本的语义误判，不能用注入标签代替真值。自动归因须按 [最小执行闭环](test-plan.md#自动归因的最小执行闭环) 取数、分析并生成有引用的报告。Langfuse 接入成功只证明观测链路可用，不能替代归因准确率验证。

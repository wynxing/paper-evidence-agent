## 1. 研究问题

两个问题分开检验：

1. **假设**：证据门槛与独立评审能减少错误的确定判断。证据门槛的定义见 [术语表](glossary.md#5-证据门槛)。
2. **假设**：结构化诊断包及轨迹能帮助测试 Agent 更准确、更快地定位缺陷。诊断包字段见 [术语表](glossary.md#6-诊断包)。

## 2. 数据

[SciFact](https://github.com/allenai/scifact/blob/master/doc/data.md) 的标签与证据来自摘要。它适合摘要级流水线自检，不能当作 PMC 全文评测结果。SciFact 结果单独报告，不与全文实验混算。

另从引文所在论文和被引文献都逐篇核实许可的 PMC 全文中，收集“论断与被引文献”配对。先导集用于改进标注指南，不并入冻结的正式测试集。

**研究目标**：正式集不少于 120 对。这是样本规模目标，不是产品验收条件，也不是已经收集到的数量。

可用 Agent 预标注以减少整理工作。用于报告准确率的真值，须由两名独立人员核对来源身份、判断标签与原文位置，分歧仲裁并报告一致性。这是研究基准的制作方式，不是产品逐条运行时的人工核验。

按论文分组切分，避免同一论文同时进入调试集和测试集。受控故障样本单列，不改变自然样本的类别比例。

## 3. 核验对照

在同一 PMC 测试集上比较四组：

1. 只给被引文献摘要的直接判定。
2. 使用相同的候选全文片段，但取消证据门槛。
3. 有证据门槛的单 Agent。
4. 加入独立评审 Agent 的完整系统。

这组对照用来检验第二次调用是否有净收益。主要对照固定模型、样本和检索预算。DeepSeek 等模型作为另行报告的跨模型实验，不通过自动回退混入主要结果。模型切换规则见 [D6](tech-stack.md#d6-模型适配)。

每次运行记录模型响应标识、参数、提示词版本、数据集与来源快照哈希，以及 token 和延迟成本。

## 4. 质量指标

分别报告：

- 可判定覆盖率
- 应拒判样本上的错误确定判断率
- 来源匹配准确率
- 证据 Recall@k
- 摘录定位有效率
- 判断 macro-F1，只在独立基准标为可判定的样本上计算

报告实际样本数、类别分布和不确定区间。覆盖率低的系统，不用条件准确率表示成整体更优。

## 5. 故障归因实验

单独注入身份错配、许可缺失、检索遗漏、上游超时和摘录错配。注入清单只供评测器使用，不放进 [输入诊断包](glossary.md#6-诊断包)。

让固定配置的测试 Agent 比较三种输入，并按样本平衡顺序：

1. 只看最终输出。
2. 看结构化诊断包，但不看轨迹。
3. 看诊断包和轨迹。

测量根因分类准确率、证据引用正确率、错误修复建议的可复现率、耗时和 token 成本。真因由注入记录和确定性断言给出，不要求人员逐例排障。轨迹无法判定的根因，允许 Agent 回答不确定。测试 Agent 的 `insufficient_evidence` 是故障归因结论，不是结果标签「证据不足」。

自然论文样本的语义误判，不能用注入标签代替真值。

## 6. 报告边界

**规则**：正式集、独立基准标注或对照实验没有完成时，研究结论停留在先导实验。将来报告的数字须指向数据版本、运行配置和原始记录。

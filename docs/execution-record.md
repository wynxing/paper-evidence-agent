### 6.1 三次都跑才看得出来的两件事

1. **汇总稳定 ≠ 判断稳定。** 逐例看，三轮标签完全一致的只有 **22/24（91.7%）**，而每轮错的两条并不相同：

   | 样本 | 人工答案 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
   | --- | --- | --- | --- | --- |
   | `PMC13648980-c04` | 部分支持 | 支持 ✗ | 支持 ✗ | 部分支持 ✓ |
   | `PMC13648980-c01` | 支持 | 支持 ✓ | 支持 ✓ | 部分支持 ✗ |
   | `PMC13648980-c05` | 证据不足 | 相矛盾 ✗ | 相矛盾 ✗ | 相矛盾 ✗ |

   前两条在「支持 ↔ 部分支持」的边界上来回摆，方向相反、各错一轮。只报「三轮都是 22/24」会把这一点盖住。

2. **`PMC13648980-c05` 三轮一致误判**（证据不足 → 相矛盾），是**系统性误判**而不是抽样噪声，也是「应拒判集错误确定判断率 0.25」的唯一来源。方向与「原文明确否定 → 相矛盾」这条判据的边界有关，属冻结期不改项。

### 6.2 复现方式

三轮的原始快照已随仓库提交（`docs/metrics-n3/run1.run.json`、`run2`、`run3`，含逐条模型回复、计数与余额变化）。**重算不花钱、不调模型**：

```bash
backend/.venv/Scripts/python.exe tests/functional/live_metrics.py <输出>.md --from docs/metrics-n3/run1.run.json
```

`--from` 只按**当前**答案集重算指标，模型输出照原样读取——所以严格来说它证明的是「这批输出 + 现在的人工答案 = 这些数字」，不是「模型今天也会这么答」。要证明后者只能重跑真模型，那会另生一笔费用，且结果不会逐字相同。

单轮的规范记录仍是 [metrics-live-86.md](metrics-live-86.md)（`live_metrics.py` 生成，不被手改，有离线回归用例 `tests/functional/test_live_metrics.py` 逐字节比对）。本节的 n = 3 是**稳定性汇总**，不替换那份单轮记录。

# 前端工作台与联调指南

前端提供新建核验、核验详情和运行诊断三个视图。后端业务路由仍是 501 占位；前端演示不证明真实文献、模型、持久化或取消执行已实现。

## 启动与模式

从仓库根目录安装锁定依赖：`npm --prefix frontend ci`。无需新增依赖。

- `npm --prefix frontend run dev:demo`：显式模拟模式，不需要后端。页面持续显示“模拟演示 · 构造数据”；所有书目、摘录和判断均为构造材料，没有真实来源链接。新任务可选择四类学术结果及排队、运行、阻断、失败、取消、中断场景。
- `npm --prefix frontend run dev`：真实接口模式。开发代理将 `/api`、`/health` 转到本机 `127.0.0.1:8000`。按 README 启动后端后，当前只能验证健康、请求校验及 501 展示。
- `npm --prefix frontend run build`：类型检查和真实模式生产构建。构建后的接口采用同源 URL，集成环境须负责路由；生产包不会自动启用模拟模式。无需部署即可用开发服务器审阅。

Hash 路由为 `#/new`、`#/checks/<id>`、`#/checks/<id>/diagnostic`。既有任务可直接进入，支持前进、后退和刷新。模拟刷新会重置构造任务集合，新建模拟任务不会恢复。

## 交互与数据边界

输入一条论断和 DOI，读取文献及当前运行配置；确认来源后再确认主用、所选备用接收方和数据范围。未授权不能提交。修改 DOI 会清空来源确认；修改论断、接收方或确认信息后需重新同意调用。服务端配置冲突会清除云授权、重新读取配置，不自动重发任务。

运行任务以 1.5 秒间隔串行查询；终态停止，页面隐藏时暂停，恢复可见时重新读取。切换任务和取消受理时会停止旧轮询，过期响应不能覆盖当前页面。取消受理与最终 CANCELLED 分开显示；连接失败不会被转换为任务 FAILED。

重新授权重试、修改原句和手动拆分均新建关联任务。原任务不会被覆盖，重试输入由后端使用原记录。反馈单独提交，不改变模型意见。仅终态可删除；本地删除不能撤回云端调用。

草稿与本次提交上下文只存于页面内存，不写 localStorage、sessionStorage 或 IndexedDB。刷新后原句可能不可读取；诊断包中的脱敏占位不用于恢复输入。缺失用量、模型版本、费用和时间不补零、不推算。

诊断页面默认读取 redacted 包。公开 DOI、题名和章节仍能识别文献，不能称为匿名包。语义导出先预览字段范围、填接收方并单独授权，再由后端校验许可并生成 consented 包；只下载到本地，不向接收方上传。默认诊断读取拒绝 consented 响应。JSON 预览和下载仅保留已声明字段，额外的完整提示词、原始响应、密钥等字段不会进入导出。

## 接口缺口清单

本任务没有修改后端或公共 API 声明。下列缺口须由前后端负责人协调后另行调整契约，当前降级不是产品要求已全部满足。

| 缺口 | 当前降级 | 后续需要协调的能力 |
| --- | --- | --- |
| 历史缺少论断摘要和时间 | DOI 与状态、保留服务端顺序，不按日期分组 | 可读摘要及可靠创建时间 |
| 详情缺少原句和完整书目 | 本次提交用内存上下文；既有任务或刷新后显示未提供 | 任务冻结输入与完整文献身份的只读返回 |
| 没有排队、开始、结束时间 | 耗时显示暂无数据，不用页面停留时间代替 | 可区分排队与执行的持久化计时 |
| 证据没有邻段上下文 | 摘录、章节、段落标识与可用来源链接 | 同版本、许可范围内的上下文读取 |
| 原句不可恢复 | 修改与拆分禁用；可确认原任务 DOI 时仍可重新授权重试 | 原始输入读取入口 |

## 检查与验收

- `npm --prefix frontend test`：Node 内置测试运行器，以类型擦除运行纯 TS 模块；要求 Node >=22.12，使用 `--experimental-strip-types`，不新增测试框架。
- `npm --prefix frontend run build`：Vue 与 TypeScript 类型检查、Vite 构建。
- Windows：`backend/.venv/Scripts/python -m pytest -c backend/pyproject.toml`，验证既有后端和公共对象形状；其他平台使用 README 的解释器路径。

浏览器验收检查：新建/文献确认/拒绝与同意授权、结果与证据页签、诊断 JSON 和导出确认、取消、重新授权重试、修改/拆分、反馈和删除确认；桌面 1440px、平板 1024px、窄屏 390px，检查长文本、横向溢出、导航、键盘及对话框焦点。真实模式需检查 501 不回退、草稿保留、网络故障和接口缺口提示。实际已执行范围记录在 verification.md，验收清单本身不表示全部通过。

# 产品需求文档：论文引文证据核验 Agent

状态：设计稿\

作者：Wynn\

相关文档：[术语表](glossary.md)、[架构设计](architecture.md)、[测试方案](test-plan.md)

句子标记见 [术语表](glossary.md)。本文只写用户可见的任务、结果、验收和范围。标签定义、任务状态和错误码不在这里重复。

## 1. 产品定位

**目标用户**：正在撰写生物医学论文、希望在提交前复查引文的作者。典型任务是：“我写的这一条具体论断，引用这篇 DOI 对应的文献是否合适？”

现有 [In-Cite Claim Check](https://www.in-cite.com/) 等产品已提供论断与来源的核验体验。本项目不以“自动判断是否支持”本身作为新颖性声明。

**假设**：在来源无法处理或证据不足时谨慎拒判，并让每个确定判断可追溯到原文。仓库内再加一名评审是否减少错误判断，留给 [研究评测](evaluation.md)，不作为参赛实现。

产品判断的是论断与指定被引文献之间的证据关系，不是论文整体质量、医学建议，也不是脱离指定文献的全领域事实核查。

## 2. 参赛边界

**规则**：本仓库走路径一。被测应用是 paper agent 这一条核验流程。参赛交付是可演示的应用，加上由仓库外的评审 agent 完成的测试方案、用例、执行记录和缺陷分析。测试怎么做见 [测试方案](test-plan.md)。

**排除**：不在仓库里实现第二名 agent，也不把 Claude 或 Cursor 接进运行时。不实现路径二那种单独发布的测试平台。不把赛题举例中的其他场景换成产品。不把研究评测的样本规模写成参赛验收。诊断包仍然生成，只交给仓库外的评审。

## 3. 首版任务与作者流程

**规则**：首版一次处理一条可独立判断的论断和一篇被引文献。作者可重复提交多条。首版支持中文或英文论断、英文 PMC 正文；不支持的正文语言明确阻断。系统不自动解析整篇稿件。

1. **FR-1** 作者输入论断原句及被引文献 DOI。输入提示要求保留原句的对象、条件、数量和结论范围。空文本、格式无效的 DOI 不进入核验。若一句包含多个难以分开的主张，提示作者拆分。作者未澄清时不输出确定判断。草稿可直接编辑；结果可提示澄清并提供修改/拆分入口，重新确认后分别创建关联原任务的新任务。已有任务输入不变，不自动把上一任务内容带入下一任务，也不增加澄清模型调用。
2. **FR-2** 系统显示该 DOI 对应的题名、作者与年份。作者确认这是拟引用的文献。无法确定时停止。解析成功不等于作者已经确认。格式错误、Crossref 未收录、注册机构暂不支持与官方解析服务当前未找到须分别说明，不把 Crossref 404 直接说成 DOI 不存在。解析来源见 [D9](tech-stack.md#d9-文献来源)。
3. **FR-3** 界面说明 paper agent 会把论断，以及从开放全文检索出的候选片段，发送给配置的模型。作者明确同意本次任务的云调用后才启动模型。授权覆盖整次任务的查询生成、判断、至多一轮补充检索及一次输出修复。界面展示主用与已配置备用接收方，以及最多四个逻辑请求、八个上游尝试的初始上限；不逐次弹窗。备用接收方未授权时不得收到数据。拒绝时保留当前页面草稿，不入队、不调用模型；拒绝授权不是核验失败。当前模型见 [D6](tech-stack.md#d6-模型适配)。
4. **FR-4** 系统按 [阶段](glossary.md#3-阶段) 展示进度。显示排队时长与执行用时，默认执行总时限 180 秒（不含排队）。允许取消排队或运行中的任务；受理时显示“正在取消”，确认本地执行结束后显示“已取消”。取消不保证撤回已发出的请求或费用。失败/超时时保留阶段与原因，提供重试入口。进度里没有内部评审步骤。
5. **FR-5** 结果页并列展示论断、文献信息、paper agent 的意见、限制、多条证据片段及位置、来源链接、判断理由、支持部分和范围差异。BLOCKED、FAILED、INTERRUPTED 和 CANCELLED 均不展示确定判断。完成有界补充检索仍没有候选或证据不够时展示「证据不足」，任务为 `COMPLETED`。结果页按具体原因区分来源阻断、处理/内容阻断与执行失败；预算耗尽给出已用/上限及重新授权指引，不能与网络故障只显示同一句“失败”。调用账不完整须展示未知，语义结果与预算核实分开。结果页不调用仓库外的评审。能否展示确定判断见 [证据门槛](glossary.md#5-证据门槛)。诊断包字段见 [术语表](glossary.md#6-诊断包)。
6. **FR-6** 作者可自愿留下意见。意见与 paper agent 的判断分开保存。产品运行不依赖逐条人工核验。
7. **FR-7** 作者可以浏览或删除本地历史。删除本地记录不能撤回此前已经发生的云模型调用。

## 4. 界面必须表达的限制

使用条件和对应状态见 [结果标签](glossary.md#1-结果标签)。下表只写界面义务。

| 展示结果 | 界面必须表达的限制 |
| --- | --- |
| 支持 | 给出对应片段及位置，不把该判断说成全领域结论。 |
| 部分支持 | 指明支持的部分，以及超出原文的部分。 |
| 相矛盾 | 展示冲突片段。仅未检索到支持片段不足以使用本标签，必须有对应条件下的冲突证据。 |
| 证据不足 | 写成“本次未获得足够证据”。不得写成文献绝对没有证据。 |
| 无法核验来源 | 给出阻断原因并停止自动判断。不得用摘要缺失代替全文否定。 |
| 执行失败 | 显示失败阶段和重试入口。任务总超时与单次上游超时分开说明。不得把它写成学术判断。 |
| 已取消 / 运行中断 | 是执行状态，不是学术结果；保留已有诊断，重试创建新任务 |

## 5. 功能边界

**首版包含**：单条论断与 DOI 输入、作者确认来源、获许可的结构化全文、限定文献的有界多步模型核验、带原文位置的结果、机器可读的诊断包、本地历史、取消/超时状态与任务内修改澄清。

**后续候选**：上传整篇论文，抽取引文句、参考文献和一对多的引用关系。含糊匹配先请作者确认，再拆成现有的单条核验。PDF 解析不是首版能力，见 [D10](tech-stack.md#d10-暂不采用)。

**排除**：

- 上传或抓取没有明确许可的全文。
- 自动改写作者论文。
- 隐式替换被引文献。
- 给论文打“真实性总分”。
- 基于摘要判定全文不支持。
- 把用户提交的未发表论断写入遥测载荷或公开数据集。

许可的自动处理范围只在 [D9](tech-stack.md#d9-文献来源) 定义。不满足时展示「无法核验来源」。

## 6. 产品验收

下列各项是实现时要满足的验收规则，不是已经测得的指标。

- **FR-8** 每次确定判断都能打开对应来源并定位摘录。摘录、来源身份或许可校验失败时，不显示确定判断。
- **FR-9** 来源不可用、许可不能自动处理、接口报错、模型响应无效，各自对应 [术语表](glossary.md) 中的不同状态和错误码，不统一写成“引用不支持”。
- **FR-10** 作者能看到整次任务的数据范围、接收方和调用预算并决定是否调用，也能浏览核验过程和 paper agent 的意见。若把含未发表论断的诊断包交给仓库外的评审 agent，须另行确认。
- **FR-11** 已创建的任务能导出有版本的诊断包。失败、阻断和取消任务的包里保留已有阶段、错误码及逐次尝试关联。redacted 包保留公开 DOI、题名和章节，预览明确“书目字段未遮盖”，不能称为匿名包。脱敏包可支持流程诊断，但语义复现需要另行授权的输入及冻结来源，不能声称仅凭脱敏元数据能复现全部缺陷。仓库外的评审按术语表的返回结构写缺陷分析，且不把任务改成另一种状态。
- **FR-12** 作者能删除本地核验记录及其关联的、未被其他任务使用的缓存。界面说明这不会删除上游服务可能保留的数据。
- **FR-13** Langfuse 导出默认关闭，须配置观测接收方并授权后启用；不可用时核验照常执行，并显示或记录观测警告。模型调用授权不自动授权观测导出。

首版必须用人工核对原文的小规模语义验收集，覆盖四类学术判断及对象、数量、条件、因果、否定方向的变化。分别报告摘录定位、语义正确情况、各类 precision/recall 与可判定覆盖率；单列相矛盾类及样本数，零分母记为不适用；所有样本都拒判不能视为准确性通过。参赛测试的维度、用例和记录见 [测试方案](test-plan.md)。120 对正式研究集不是首版前置条件。见 [研究评测](evaluation.md)。

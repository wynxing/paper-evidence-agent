# 产品需求文档：论文引文证据核验 Agent

> 状态：设计稿。下述流程、界面和指标均为待实现与待验证的要求，不代表已有用户数据或实验结果。

## 1. 产品定位

**目标用户**：正在撰写生物医学论文、希望在提交前复查引文的作者。典型任务是：“我写的这一条具体论断，引用这篇 DOI 对应的文献是否合适？”

现有 [In-Cite Claim Check](https://www.in-cite.com/) 等产品已提供论断与来源的核验体验。因此本项目不以“自动判断是否支持”本身宣称新颖，而将以下内容作为待检验的研究方向：在来源无法处理或证据不足时谨慎拒判、让每个确定判断可追溯到原文、让独立评审 Agent 检查判断并让测试 Agent 借助结构化证据包与执行轨迹定位错误。这些目标只有在对照实验成立后才能写成成果。

产品判断的是**论断与指定被引文献之间的证据关系**，不是论文整体质量、医学建议，也不是脱离指定文献的全领域事实核查。

## 2. 首版任务与作者流程

首版一次处理一条可独立判断的论断和一篇被引文献。作者可重复提交多条，但系统不自动解析整篇稿件。

1. 作者输入论断原句及被引文献 DOI。输入提示要求保留原句的对象、条件、数量和结论范围；空文本、格式无效的 DOI 不进入核验。若一句包含多个难以分开的主张，提示作者拆分；作者未澄清时不输出确定判断。
2. 系统通过 Crossref 显示 DOI 对应的题名、作者与年份。作者确认这是拟引用的文献；无法确定时停止。仅有 DOI 可解析不等于引用身份已得到作者确认。
3. 界面说明初判与评审会把论断和从开放全文检索的候选片段发送给 Agnes。作者明确同意本次调用后才启动模型；拒绝时可停止，且不以拒绝授权作为核验失败。
4. 系统展示“等待、核对来源、检查许可、获取全文、检索证据、初判、独立评审、证据校验”等进度。评审 Agent 在隔离上下文中先独立检索和判断，再检查初判证据；失败时保留阶段与原因，并提供重试入口。
5. 结果页并列展示论断、文献信息、初判与评审意见、分歧或限制、原文片段及位置、来源链接。双方分歧、评审失败或证据门槛不通过时，不展示单一的确定结论；输出可供测试 Agent 分析的诊断包。作者可自愿留下意见，但产品运行不依赖逐条人工核验。作者也能浏览或删除本地历史；删除本地记录不能撤回此前已发生的云模型调用。

## 3. 判断与失败语义

| 展示结果 | 使用条件 | 界面必须表达的限制 |
| --- | --- | --- |
| 支持 | 所指定文献的可定位原文在相同对象和条件下支持该论断 | 给出对应片段及位置，不延伸成全领域真理。 |
| 部分支持 | 原文支持主张的一部分，但数量、对象、因果性或适用范围等存在重要差异 | 指明支持部分与超出原文的部分。 |
| 相矛盾 | 原文在对应条件下明确给出相反证据 | 展示冲突片段；不能只因没有检索到支持片段而使用此标签。 |
| 证据不足 | 已取得并处理获许可的目标全文，但现有可核查片段不足以作出上述判断 | 表述为“本次未获得足够证据”，不能宣称文献绝对没有证据。 |
| 无法核验来源 | DOI 或文献身份无法确认、无合规全文、版本/许可不清、提取完整性不足 | 返回明确的阻断原因，停止自动判断；不能用摘要的缺失代替全文否定。 |
| 执行失败 | 外部接口、任务执行或模型输出校验失败 | 显示失败阶段和可重试信息；这不是学术判断。 |

确定判断（前三类）必须同时满足：目标 DOI/PMCID 身份一致、所用版本和许可可记录、证据摘录能在保存的原文段落中逐字定位，且独立评审 Agent 对来源、关键条件与标签无实质性异议。证据校验不通过或双方分歧时撤回单一确定判断，保留各自输出。两名 Agent 一致也只是通过产品门槛，并非客观真值。

## 4. 功能边界

**首版包含**：单条论断＋DOI 输入、作者确认来源、获许可的 PMC 结构化全文、限定文献的初判与独立 Agent 评审、带原文位置的结果、机器可读的证据与诊断包、本地历史与错误状态。OpenAlex 仅用于发现可用位置线索，自动全文获取遵守 PMC 官方渠道与逐篇许可。[PMC 规则](https://pmc.ncbi.nlm.nih.gov/tools/oai/)

**后续候选能力**：上传整篇论文，抽取引文句、参考文献和一对多的引用关系；对含糊匹配先请作者确认，再逐条核验。PDF 解析可评估 GROBID，但必须单独测量引文映射错误，不能让解析结果直接冒充确定的引用关系。[GROBID 接口](https://grobid.readthedocs.io/en/latest/Grobid-service/)

**不包含**：上传或抓取无明确许可的全文、自动改写作者论文、隐式替换被引文献、给论文打“真实性总分”、基于摘要判定全文不支持。用户提交的未发表论断不写入遥测载荷或公开数据集。

## 5. 产品验收与研究指标

以下是将来实施时的验收规则，不是已经达成的指标：

- 每次确定判断均能打开对应来源并定位摘录；摘录、来源身份或许可校验失败时不显示确定判断。
- 来源不可用、许可不明确、接口报错、模型响应无效，各自有不同状态；不会统一写成“引用不支持”。
- 作者能看到两次模型调用的数据范围并决定是否调用；可浏览核验过程和两名 Agent 的意见。向外部测试 Agent 传递未发表论断时，须另行确认。
- 测试 Agent 可读取有版本的诊断包，按证据位置和阶段错误码提出可复现的缺陷假设；其报告须区分已验证事实与待验证推测。
- 作者能删除本地核验记录及其关联的非共享缓存；界面说明这不会删除上游服务可能保留的数据。
- 研究评估分别报告：可判定覆盖率、在应拒判样本上的错误确定判断率、证据检索率、可判定样本的判断质量，以及测试 Agent 的错误定位准确率和用时。评测集、基线与统计方式见 [架构设计](architecture.md#6-研究评测设计)。

商业价值、研究新颖性和使用体验尚未得到验证。只有与现有做法在相同样本上比较，才能决定该产品和论文方向是否值得继续扩大。

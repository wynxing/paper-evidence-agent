# Paper Evidence Agent

本项目旨在核对论文中的论断与所引文献之间的证据关系。目标是让核验 Agent 提供可定位的原文依据，让独立评审 Agent 复查判断，并向测试 Agent 输出可诊断的证据与执行记录。系统应标明证据不足或来源无法获取的情况；Agent 间意见一致也不自动等于事实正确。
